# 8. OdinViewer Quick Start

📄 [Download English PDF: OdinViewer v0.1.1 User Manual]({{ '/odin_series/odin1/assets/pdf/OdinViewer-v0.1.1-User-Manual.pdf' | relative_url }})

📄 [下载中文PDF：OdinViewer v0.1.1 使用手册]({{ '/odin_series/odin1/assets/pdf/OdinViewer%20v0.1.1%20使用手册（零基础版）.pdf' | relative_url }})

> ⚠️ **Important: OdinViewer is NOT compatible with firmware 0.12.0 or later**
>
> Starting from Odin1 firmware **0.12.0**, the communication protocol between the device and the host SDK has changed. OdinViewer (current release v0.1.1) **cannot communicate correctly with firmware 0.12.0 or later**.
>
> - If your device firmware is **≤ 0.11.x**, you can continue to follow this chapter to use OdinViewer.
> - If your device firmware is **≥ 0.12.0**, please switch to the **Ubuntu + ROS Driver** workflow (see [7. Odin1 Quick start for ubuntu](./7.%20Odin1%20Quick%20start%20for%20ubuntu.html)) or wait for the next OdinViewer release.

## 8.1 Hardware Setup

Hardware: Odin1 main unit, data cable, power cable (the power adapter must be supplied by the user).

PC: Windows.

## 8.2 Software

- [Odin Viewer]({{ '/odin_series/odin1/assets/software/OdinViewer0.1.0.7z' | relative_url }})

## 8.3 Connect the Device to the PC

- Power the Odin1 main unit with a 12V / 2A adapter.
- Plug the data cable into a USB port on the PC.

## 8.4 Install the Driver

- Download Odin Viewer via the link in 8.2, extract the archive, locate the `USBTools` folder, and double-click `zadig-2.9.exe`.
- Open the drop-down list, select the `hawk` device (i.e. Odin1), then click **Install Driver** and wait for the installation to complete.

> Note: each PC only needs to install the driver once; subsequent uses do not require reinstallation.

## 8.5 Run the Software

Double-click `OdinViewer.exe` to launch the software. Point cloud and image data will be displayed automatically.

## 8.6 Record Data

- OdinViewer only supports recording in the `olx` format. Click **Start Recording** in the bottom-right corner to start, and click **Stop Recording** to stop.
- Recordings are saved to the `recorddata` folder next to the application.
