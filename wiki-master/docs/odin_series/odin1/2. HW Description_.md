# 2. 硬件说明

## 2.1 物理接口

![](assets/img/17.png)

| 序号 | 接口类型 | 线缆型号 | 功能描述 |
| :-: |:-: |:-: | :--: |
| 1 | 四芯航空插座 | FGG.0T系列推拉自锁插头 | 供电接口 |
| 2 | USB-C 3.0 | USB 3.0 | 高速数据输出 |

## 2.2 接口定义


![](assets/img/18.png){:width="30%"}

| 四芯航空插座管脚 | 信号   | 属性  | 描述 | 线束颜色 | 功能 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| 1 | Power+ | Power | DC 12–24V | 红(正极) | 电源线 |
| 2 | No Connection |  |  |  |  |
| 3 | GP IO | GP IO | 双向同步IO   | 白 | GP IO（预留，暂未使用） |
| 4 | Ground | Power | Ground | 黑 (负极) | 电源线 |

## 2.3 核心部件

![](assets/img/19.png)

| 序号 | 部件 |
| :-: | :-: |
| 1 | 激光发射端(TX) |
| 2 | 激光接收端(RX) |
| 3 | RGB相机 |
